# GI Resident AI V24.1

消化内科住院医师规范化培训辅助教学系统。公开网页提供病例推理、动态病程、并发症抢救、报告质控、多模态病例、内镜解剖与操作认知、错题复习和学习记录等功能。

## 在线使用

网站部署完成后访问：<https://baekie56.github.io/gi-resident-ai-v24-1/>

网页是可安装的 PWA。第一次需要联网完整打开；资源缓存完成后，可从手机或电脑主屏幕启动，在网络不稳定或暂时断网时继续使用。学习记录保存在当前浏览器，请定期在“学习记录”中导出备份。

## 数据模式

- GitHub Pages 是静态公开站点，只提供本机离线档案，不集中保存规培生数据。
- Windows 服务器版支持独立账户、集中 SQLite 数据库、操作记录和管理员复核；启动方法见 `README_DEVELOPER.md`。
- 公网集中版使用容器镜像 `ghcr.io/baekie56/gi-resident-ai-v24-1:latest`，部署参数见 `DEPLOY_CHINA.md`。管理员可统一查看各学员的登录、导航、训练开始、提交、完成或退出时间，以及成绩、训练时长和原始作答。
- 请使用学习代号，避免录入患者姓名、病历号或其他真实身份信息。

## 源码结构

- `web/`：公开网页和 PWA。
- `backend.py`：班级服务器、账户、训练记录和管理员接口。
- `desktop.py`：Windows 桌面控制器。
- `updates.py`、`publisher.py`：签名内容更新。
- `tests/`、`web/tests/`：自动化测试。

## 使用边界

本项目用于形成性教学，不替代临床诊断、带教教师考核或内镜操作资质认证。病例内容、评分规则及图片授权状态应在正式教学或研究前完成专科与伦理审查。仓库未附开源许可证，第三方素材的权利状态以 `web/docs/ASSET_REGISTER.csv` 为准。

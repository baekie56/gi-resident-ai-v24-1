# 用户使用手册

软件：消化内科住院医师规范化培训辅助教学系统 V24.0（GI Resident AI）。

## 安装与启动

要求：Windows 10/11、现代 Edge/Chrome、Python 3.10+；建议 1280×720 或更高分辨率。技术检查在 Python 3.14 / Node.js 24 执行；Node.js 仅用于开发测试。

完整解压后双击 `START_WINDOWS.bat`，访问 `http://127.0.0.1:8000/`。若端口冲突，在解压目录终端执行 `python server.py --port 8010`，打开相应地址。退出前等页面显示保存成功，再关闭服务器窗口。

脚本不会自动安装软件。找不到 Python 时安装后重试；图片缺失时重新完整解压，不要只复制 HTML。

## 学员操作

1. 注册独立用户名和 10—128 位密码，不使用患者姓名或病历号。
2. 今日学习可进入固定每日计划，或从病例推理筛选出血和胰胆急症。
3. 学习模式：问诊、选择教学检查，分别填写诊断、鉴别和计划。文本核对仅提示表达覆盖，未命中不等于医学错误。
4. 自测练习：从病例库切换，按主诉选择病例。隐藏诊断标题和即时标准答案，完成后统一复盘。同题库可能已学过，不能作为独立考试终点。
5. 每道决策选择后锁定，点击下一题继续；未完成退出显示“中途退出”。
6. 学习记录保留首次、重练、最近一轮和教师反馈，决策与表达覆盖不合成为临床能力评分。
7. 内镜先逐步浏览教程，再进入流程练习。鼠标位置、生命值、游戏用时不对应真实操作能力。

报告模块分别显示填写完整度和内容覆盖，任意填写不能凭字段数量获取内容分。未被规则识别的合理答案请交导师复核。

## 教师操作

在同一解压目录双击 `CREATE_TEACHER.bat`，输入新教师用户名和密码，密码不回显。无固定教师邀请码。随后通过网页登录该账户。

教师可查看本机服务中的学员、原始作答和版本，为具体轮次记录独立反馈，不覆盖原始回答。“已完成复核”代表完成本次反馈，不代表操作授权。

内容审核台账需填写审核人、日期、适用人群、依据条款、合理替代答案及安全遗漏标准，再确定住培阶段。不能只凭“困难/核心”标签安排独立操作。

## 保存、导出与备份

服务器数据库默认 `private/gi24.sqlite3`；密码加盐 PBKDF2 保存，教师页面和学习导出不含密码材料。服务器数据不缓存到浏览器学习档案，主机管理员仍能接触数据库。

显示“待保存”或“保存失败”时不要直接退出，恢复连接会重试。冲突说明其他窗口更新了同一档案，先导出本页学习备份，再重新登录。避免多窗口同时编辑。刷新会丢失未提交、未写入轮次记录的活动草稿。

- 学习备份保留档案名称、原始文本，不包含登录密码；不能当作匿名研究表。
- 研究 CSV/JSON 默认随机研究编号、无用户名或自由文本，但时间和轨迹仍可能被关联。
- 勾选包含原始回答后，问答和报告可能带身份信息，核查后再共享。
- 离线教师工作台可恢复 V24 备份为独立档案，同名不覆盖；丢弃旧缓存中的可执行计划，随后重建。
- 服务器完整备份：关闭服务后复制整个 `private` 文件夹，包括存在的 SQLite 辅助文件。恢复前备份当前目录，服务关闭时放回。学习 JSON 不能恢复服务器账户和教师审核表。

单次同步/导入上限 8 MB。接近此规模应先设计分批同步与归档，当前版不适合长期大规模采集。没有一键删除全部数据功能。

## 离线体验与旧版数据

双击 index.html 选择离线体验，数据限当前浏览器和地址；换浏览器、移动路径、清理存储可能无法看到旧档案。离线教师只是本机汇总，没有鉴权。

V23/V24 使用不同存储键，不自动迁移原账户或覆盖旧数据。先用原程序导出并保留 V23 原文件；未经校验的旧 JSON 不直接导入。

## 可选联网患者问答

服务器管理员启动前设置 `OPENAI_API_KEY`、`OPENAI_MODEL` 环境变量；模型须为账户实际可用的 Responses 模型。密钥不写进前端、源码或 ZIP。

学员在学习模式明确勾选后才发送患者可知教学资料、问题及最近问答片段，自测不启用。接口使用独立角色指令、`store: false`，记录返回模型与提示版本。该参数不等于零数据保留承诺，应按服务政策和单位要求配置。

失败回退本地规则问答。本包未配置密钥、未执行付费联网测试；模型可能补造细节，仍需教师核查。默认本地功能无需联网。

| 常见问题 | 处理 |
|---|---|
| 页面打不开 | 检查服务器窗口、端口与完整目录 |
| 记录不见 | 检查服务器/离线模式、浏览器、数据库目录 |
| 图片失败 | 停止本页练习，完整解压后重新进入 |
| 教师注册不了 | 用 CREATE_TEACHER.bat，网页仅注册学员 |
| 同步冲突 | 导出本页备份，退出其他窗口后重新登录 |
| 合理答案未认可 | 保留原文，请教师单独反馈 |

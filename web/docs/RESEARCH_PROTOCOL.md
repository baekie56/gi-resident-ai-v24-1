# 住培教学研究方案准备稿

本版为形成性学习工具，未开展 V24 有效性研究。以下为待研究团队修订的设计，不是已有结果。

## 分阶段实施

第一阶段：由有实际带教资格的专科教师独立审核病例、指南适用性、图像标签、替代答案和关键安全错误，记录分歧与仲裁。建立正确、同义、否定、矛盾、易混疾病和限定条件缺失的答案集，验证规则误判，单独报告安全相关错误。

第二阶段：小规模可行性试用，观察流程完成、操作失败、教师工作量和可用性；访谈合理但未识别表达。样本量按可行性目标与估计精度决定，不把便利样本解释为充分的效果证明。正式研究前冻结软件、题库、提示词和手册。

第三阶段：比较“常规带教 + 固定剂量系统学习”与常规带教的教育效果。优先前瞻性随机对照，控制学习时间；按学员随机需防组间污染，按轮转组集群随机须处理聚类。

| 设计要素 | 预先明确 |
|---|---|
| 主要结局 | 独立、未在系统训练过的平行病例或 OSCE，盲法教师按审定量表评分 |
| 时间点 | 基线、教学结束、延迟保留测评；间隔结合课程 |
| 次要结局 | 安全遗漏、知识、保留、可用性、教师时间 |
| 干预剂量 | 每周病例数、时长、教师反馈频次 |
| 背景/暴露 | 住培年级、经验、既往见题、其他学习资源 |
| 样本量 | 按主要结局、有意义差异、方差/ICC、效能和脱落计算；尚未填人数 |
| 统计 | 预注册主要模型，处理基线、重复和集群，报告效应量与置信区间 |
| 退出/缺失 | 预先定义，不事后排除低分学员 |

系统内最高分或同题重练不证明外部能力提高。“首次”只表示记录中的首次，不能保证未见题。平行测评、盲法评分、量表和正式样本量仍需完成。

## AI 的实际角色

默认干预是本地规则问答、核对、图像和流程交互；大模型仅可选扮演患者，不评分诊断或识别图像。研究应禁用联网问答以固定干预，或明确配置并记录模型、提示词、失败回退及成本，不能混合成未定义干预。

## 伦理与数据

招募和前瞻性采集前向本单位伦理部门确认路径，按要求取得审批、同意或豁免。说明带教关系中的自愿参与、退出、与常规考核关系及数据访问者，不能自称教学研究一律免伦理。依据：[涉及人的生命科学和医学研究伦理审查办法](https://www.nhc.gov.cn/wjw/c100375/202302/902b4a1dc3af4aba862a6387e6e376dc.shtml)。

仅用虚拟病例；真实患者素材另行授权、去标识。预定保存期限、访问、跨境处理及编号对应表分开保管。随机研究编号不保证绝对匿名。

## 论文写作

方法交代内容审核、实际功能、分组、剂量、独立测评与统计；结果报告真实招募、依从性、结局和误导性反馈；讨论同题学习、单中心、规则局限及推广范围。不预写效应、显著性或虚构参与者。

随机试验按 [CONSORT（EQUATOR）](https://www.equator-network.org/reporting-guidelines/consort/)核对；干预符合适用范围时再对照 [CONSORT-AI](https://www.nature.com/articles/s41591-020-1034-x)，不能因名称含 AI 就宣称符合特定临床 AI 扩展。

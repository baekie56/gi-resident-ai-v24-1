# 电脑与手机应用使用说明

## 集中记录与管理员查看

正式试用时，请由维护者在 Windows 控制器的“数据与管理员”页创建管理员账户，并启动班级服务器。规培生使用各自服务器账号登录；不要用离线学习代号代替正式研究账号。管理员在同一入口登录后进入“管理员总览”，可按规培生查看操作时间、训练时长、成绩、完成或退出状态、逐题记录和管理员反馈，并可导出训练明细 CSV。

班级服务器运行期间必须保持维护电脑开机，并定期使用控制器的数据库备份功能。公开静态手机版不连接该数据库，适合演示或个人练习，不用于集中科研采集。

Windows 用户：双击 GI_Resident_AI.exe，在软件与更新中心点“进入学习”。不用安装 Python。管理员在“数据与管理员”页创建账户；“软件更新”支持导入签名更新包、配置可选在线更新源及回退。关闭学习页面并确认保存后再更新。

电脑数据库独立保存在当前 Windows 用户的 `%LOCALAPPDATA%\GIResidentAI\data`，重解压或移动 EXE 不覆盖。完整备份入口在“数据与管理员”。普通“进入学习”仅监听本机；点击“启动班级服务器并查看管理员后台”后，同一可信网络中的手机和电脑可通过界面显示的局域网地址连接。

手机用户：需要由维护者提供 HTTPS 网站地址。安卓浏览器菜单选择安装或添加主屏幕；苹果 Safari 分享菜单选择添加主屏幕。首次联网完成缓存后支持离线学习，更新在缓存准备好后提示，结束训练后再切换。主屏幕安装取决于实际浏览器支持。

静态手机网页使用本机学习代号；没有服务器账号同步，记录只属于当前手机和网页地址。手机与电脑数据不会自动合并。定期在学习记录页导出备份，勿通过删除浏览器存储来更新软件。

学习流程沿用 V24：病例问诊与决策、文本表达覆盖、逐步内镜教程、学习记录、研究导出。分数不是医学正确率或操作资格。临床审核和图片许可台账仍须维护。

V24 原版数据库迁移：关闭原 Python 服务和新软件，备份两边数据；将原 `private` 中数据库及相关辅助文件保存一份完整备份，再由熟悉数据库的人在新软件数据目录恢复。不要在服务运行时覆盖数据库。原 V24 浏览器档案需在原程序导出，不能仅复制 EXE 自动迁移。

界面中文字、病例或图片需要调整时，维护者可修改维护包的 web 源码并生成更高版本 `.giupdate`。后端或数据库结构升级需重新构建主程序，并先验证迁移兼容性。

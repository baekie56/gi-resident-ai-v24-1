GI Resident AI · V24.1

消化内科住培辅助教学

病例推理、急症决策、内镜认知与教师复盘。

  1. 完整解压这个文件夹。
  2. 安装 Python 3.10 或更高版本后，双击文件夹中的 START_WINDOWS.bat。
  3. 在自动打开的页面注册学员。教师请先双击 CREATE_TEACHER.bat 创建账户。
  4. 先做常见出血、胆道感染和胰腺炎病例，再由导师安排拓展训练。
无 Python 时可进入离线体验；数据仅保存在当前浏览器，离线工作台不提供身份隔离。

# 消化内科住院医师规范化培训辅助教学系统 V24.0

英文简称 GI Resident AI；内部版本 24.0.0；题库版本 2026-09-06.1。

面向消化内科轮转住培学员和带教教师，用于病例推理、内镜识图、流程认知和形成性反馈。本版保留原包 32 个基础病例、98 道病例决策题、9 类术式及图像。核心教学内容仍需专科签审。

## 开始使用

1. 完整解压到可写目录，不要在 ZIP 内直接运行。
2. 安装 Python 3.10 或更高版本；无需第三方 Python 包。
3. Windows 双击 `START_WINDOWS.bat`，打开 `http://127.0.0.1:8000/`，服务器窗口保持开启。
4. 注册学员账户。教师先双击 `CREATE_TEACHER.bat` 创建独立账户，再登录。
5. 没有 Python 时可双击 `index.html` 离线体验；离线档案限当前浏览器，离线教师工作台不提供身份隔离。

建议先练出血、胆道感染和胰腺炎，再由导师安排内镜拓展。详见 [使用手册](docs/USER_MANUAL.md)。

## 主要变化

- 删除近似医学词自动纠错；完整表达、明确同义词及否定/条件检查取代宽松评分。
- 决策练习、表达覆盖、报告填写完整度分开，不作为医学正确率或能力认证。
- 自测隐藏诊断标题和即时解析；选项随机排序并记录原始索引。
- 当日计划保存具体项目，完成后不重新打乱；保留复习到期时间。
- 本机 SQLite、独立账户、追加式轮次记录、单独教师反馈。
- 研究导出默认使用随机编号并排除自由文本；学习备份不包含密码材料。
- FNA/FNB 共享细胞学示例明确标注，教程逐步浏览，缺图暂停图像练习。

本机服务仅绑定 127.0.0.1，同电脑不同浏览器可访问同一数据库。未部署跨电脑平台；局域网或公网使用需另行实现 HTTPS、部署权限和运维管理。

联网患者问答默认关闭，无密钥也能完成全部本地教学流程。系统没有大模型自动诊断、影像推理或经过验证的临床语义评分。

医学签审、图片传播权、实际著作权人和研究伦理审批均未由此次技术修改代为完成。申报材料是可填写草稿，不是登记证书或论文有效性证明。

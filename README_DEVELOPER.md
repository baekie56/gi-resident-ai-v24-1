# GI Resident AI — 电脑与手机应用维护包

桌面运行时 1.1.0；内容版本 1.1.0；兼容 V24 学习数据引擎 24.0.0。

## V24.1 集中记录与管理员后台

本版新增追加式训练记录、操作日志和管理员汇总。规培生用服务器账户登录后，每次开始训练、提交作答、完成或中途退出都会形成时间记录；完成轮次会立即单独写入 SQLite，之后再同步完整学习档案。网络短暂中断时，待上传记录暂存在本机队列，重新连接后自动重试。

服务器版还提供集中式“管理员内容管理”。管理员可创建病例草稿，填写问诊规则、检查结果、诊断/鉴别/处置评分点、教学要点和决策题，上传 PNG/JPEG/WebP 图片，并在完成专科审核后发布。草稿修改不会立刻影响学员；再次发布后全部服务器账户读取新版本。停用病例不删除历史训练，训练记录会保存对应的内容版本。

维护者先在“数据与管理员”页创建管理员账户，再点“启动班级服务器并查看管理员后台”。同一可信网络中的规培生可用手机或电脑打开界面显示的班级地址，各自注册账号。管理员登录后可以按规培生查看最近活动、训练开始和结束时间、累计时长、成绩、首次或重练、退出记录、逐题原始记录与反馈，并可导出管理员训练明细 CSV。

班级服务器需要维护电脑保持开机，且学员设备能访问该电脑的 8765 端口。院外或互联网正式研究应部署带 HTTPS、备份和访问控制的专用服务器；公开静态 PWA 仍只保存各手机自己的档案，不能冒充集中数据库。

## 你以后怎样更新

保留这个完整源码目录，主要修改 `web` 文件夹中的病例、文字、样式和图片。也可以继续把这个项目交给助手修改，再用桌面软件的“我的发布工具”选择 `web`，输入更高版本号，例如 1.0.1，生成 `.giupdate`，同时得到 GI-web-版本号.zip 手机部署包。

学员打开软件的“软件更新 → 导入更新包”，即可切换内容，账户和记录保留。导入前必须结束训练、确认已保存并关闭学习窗口。更新包包含整套内容，不含学员数据。没有服务器也可以直接分发更新包。

发布私钥只保存在你的 Windows 用户目录：`%LOCALAPPDATA%\GIResidentAI_Publisher\publisher.ed25519`。本维护 ZIP、学员 EXE 和更新包都不包含私钥。请自行另做私密备份，勿发给学员；迁移维护电脑需恢复该私钥。`release-public.key` 是可公开的验证公钥。丢失私钥后旧软件无法接受新签名包，需要发行更换验证公钥的新主程序。

“发布”是打包、校验和签名，不是自动编写临床内容。涉及病例和评分标准的改动仍须教师复核，发布说明记录改动范围。

## 两种更新范围

| 更新内容 | 处理方式 |
|---|---|
| 页面、题库、图片、教程、CSS、前端规则 | 生成 `.giupdate`，内容版本递增 |
| Python 后端、账户结构、桌面窗口、数据库迁移、内置公钥 | 修改根目录代码，测试后重新构建 EXE；不能通过内容包改变后端 |

更新前自动创建 SQLite 备份，校验通过才原子切换版本指针。回退只切换教学内容，保留最新学习记录，不回退数据库。原始记录保留当时题库版本 `desktop-版本号` 以及 distributionVersion。

当前签名验证防止来自其他密钥或被篡改的更新包通过导入；它不是 Windows 代码签名证书，也不防本机管理员修改数据。EXE 未做商业代码签名。

## 电脑运行

学员只需 `GI_Resident_AI.exe`，无需 Python，建议 Windows 10/11 64 位及 Edge/Chrome。EXE 首次解包后显示软件与更新中心，点击“进入学习”打开独立浏览器应用窗口；这是桌面控制器加本机教学服务，不是另行重写的浏览器内核。保持控制器开启，退出后服务停止。占用固定本机端口 8765，不开放局域网。

数据固定在 `%LOCALAPPDATA%\GIResidentAI\data\gi24.sqlite3`，移动 EXE 不改变数据路径。数据库包含账户、不可覆盖的完成轮次、操作日志和管理员反馈。离线浏览器模式的档案另存在浏览器中，不等于服务器数据库。

## 手机部署与更新

将 `GI_Resident_AI_Mobile_Web.zip` 的全部文件部署到一个 HTTPS 网站目录，保留目录关系；在安卓 Chrome/Edge 或苹果 Safari 中打开，可通过浏览器菜单添加到主屏幕。没有 HTTPS 网站时，不能把电脑本机 127.0.0.1 地址发给手机使用。尚未随本包创建公网网站、域名或应用商店上架。

手机版采用 PWA。首次需要联网完整缓存；缓存准备完成后可离线学习。直接部署 `GI_Resident_AI_Mobile_Web.zip` 得到的是静态版，数据仍只在各自手机。需要集中记录时，应让手机访问维护电脑启动的班级服务器，或部署带鉴权和 HTTPS 的正式后端。

后续使用发布工具同时生成的 GI-web-版本号.zip 部署新版网站：先准备完整版本目录，再原子切换网站目录。保持网站域名及路径不变，避免丢失原地址对应的本地档案。不要清理浏览器存储来更新。网页会检测服务工作线程更新，缓存完整后提示；结束训练、导出重要备份、关闭其他学习标签页，再点“保存后更新并重开”。API 和账户响应不进入离线缓存。

当前脚本会在打包时生成带版本的 sw.js；不能只修改网页文件而不重新打包，否则离线用户可能仍使用旧缓存。iOS/安卓真机及第三方浏览器差异仍需部署后核验。

## 可选在线更新源

在“我的发布工具”填入更新包未来的 HTTPS 下载地址，生成包时会同时生成签名 `latest.json`。把这两个文件放到你有权限管理的网站；在学员“软件更新”页配置 latest.json 的 HTTPS 地址，再点检查更新。当前默认没有在线地址，没有静默下载或强制自动安装。

不使用 GitHub 帐号、密码或密钥作内置配置；本次未发布任何外部资源。更新服务器只需托管静态文件，更新清单及包都校验签名。

## 源码构建与测试

安装 Python 3.10+（此包构建验证使用 3.14）、Node.js（仅测试）和 requirements-build.txt 依赖，在此目录运行 `python build.py`。初次构建会读取或生成本机发布密钥，生成 EXE、初始更新包和手机部署 ZIP。重建初始版时不能覆盖已经分发的同版本内容，应同时调整构建版本并记录发布历史。

```text
python tests/test_updates.py
python tests/test_backend.py
node --test web/tests/core.test.cjs
node --test tests/pwa.test.cjs
```

版本功能依据：[PyInstaller 运行方式](https://www.pyinstaller.org/en/stable/operating-mode.html)、[MDN PWA 安装要求](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)、[Cryptography Ed25519 签名](https://cryptography.io/en/latest/hazmat/primitives/asymmetric/ed25519/)。
